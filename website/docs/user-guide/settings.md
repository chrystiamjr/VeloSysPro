# Settings

The Settings screen centralizes preferences that affect the entire VeloSys Pro experience.

![VeloSys Pro Settings screen](/img/screenshots/settings.png)

## Language {#language}

Switch between English (US) and Portuguese (Brazil) instantly. The interface, status messages, and
live execution logs follow the selected language.

## Safety backup {#safety-backup}

Enable the safety-backup preference to create a registry backup before supported optimization plans
change system settings.

## Updates {#updates}

The installed version and any available GitHub release remain visible from Settings, including after
an update notification has been dismissed.
