# Configurações

A tela de Configurações centraliza as preferências que afetam toda a experiência do VeloSys Pro.

![Tela de Configurações do VeloSys Pro](/img/screenshots/settings.png)

## Idioma

Alterne instantaneamente entre inglês (Estados Unidos) e português (Brasil). A interface, as
mensagens de status e os logs de execução acompanham o idioma selecionado.

## Backup de segurança

Ative a preferência de backup de segurança para criar um backup do Registro antes que os planos de
otimização compatíveis alterem configurações do sistema.

## Atualizações

A versão instalada e qualquer nova versão disponível no GitHub permanecem visíveis nas
Configurações, inclusive depois que uma notificação de atualização é dispensada.
