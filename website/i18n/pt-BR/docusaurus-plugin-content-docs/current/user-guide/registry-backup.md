# Backup e Restauração do Registro

Antes de aplicar ajustes de sistema ou rede, o VeloSys Pro oferece ferramentas integradas de segurança para o registro.

## Criando um Backup do Registro

1. Navegue até a aba **Backup & Restauração** no VeloSys Pro.
2. Clique em **Criar Backup Agora**.
3. Um snapshot `.reg` das suas configurações atuais de rede e TCP/IP será exportado com carimbo de data/hora no diretório `%LOCALAPPDATA%\VeloSysPro\backups`.

## Restaurando um Backup

1. Selecione um backup na tabela.
2. Clique em **Restaurar** e confirme a caixa de diálogo.
3. O VeloSys Pro importa o arquivo `.reg` selecionado diretamente para o Registro do Windows.
