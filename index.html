💻 Headless CLI Execution

VeloSys Pro supports silent background task execution for Windows Task Scheduler or automated scripts.

# Run Quick Optimization headlessly
.\VeloSysPro.exe --task=quick

# Enable Gaming Mode optimizations
.\VeloSysPro.exe --task=gaming
